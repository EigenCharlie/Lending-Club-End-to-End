Explainable Boosted Scoring with Python ⤵
⭐ GitHub repo: https://lnkd.in/dag5Kqwf
📚 Documentation: https://xrisklab.ai/
If you like credit scorecards and gradient boosting, this repo is for you! 🚀
The xbooster library is specifically designed for productionizing credit scorecards using gradient boosted decision trees 🌳. It extends XGBoost's logistic regression framework, tailored to meet the needs of model developers and validators working in the risk management domain 🏦
What can xbooster do for you?
▹ Boost Model Accuracy: Enhance predictive performance of the scorecards with ML.
▹ Open Up the 'Black-Box': Utilize tree visualization and understand global and local importance of features.
▹ Simplify Deployment and Validation: Deploy scorecards effortlessly using SQL and reduce validation efforts.
Install with pip install xbooster 🌟
➡️ Medium article: https://lnkd.in/dWniT28T
