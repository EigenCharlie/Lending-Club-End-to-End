README
On Credit
Scoring Foundations in the Age of AI
Denis Burakov
This repository contains the code and Jupyter notebooks for On Credit: Scoring Foundations in the Age of AI.
Contents
Chapter
Topics
1. Weight of Evidence
WOE, Banburismus, MacKay–Turing
2. Logistic Regression
Binary/multinomial logistic, WOE–logistic link, gradient descent, log-loss
3. Deep Learning
XOR, MLPs, credit scorecard MLP, contour plots, attention
4. The Credit Game
Trees, SHAP, scorecards, Fisher–Yates, information gain, two cultures
Requirements
Python 3.11
uv (recommended) or pip
LaTeX (optional, for some notebook outputs) — e.g. MacTeX on macOS
Setup
Clone the repo, then install dependencies with uv:
uv sync --dev
If you use MacTeX, ensure texbin is on your PATH:
export PATH="/Library/TeX/texbin:$PATH"
Run any notebook with Jupyter (e.g. from the repo root):
uv run jupyter notebook
# or
uv run jupyter lab
Project layout
├── book-cover.jpg
├── pyproject.toml
├── data/
├── ch01-weight-of-evidence/
├── ch02-logistic-regression/
├── ch03-deep-learning/
└── ch04-credit-game/
Dependencies are listed in pyproject.toml (e.g. pandas, scikit-learn, shap, xgboost, catboost, statsmodels, matplotlib, seaborn).
