A Conceptual Note Understanding what trees predict is essential for interpreting ensemble models: • Random Forests: Each tree is a classification tree that predicts class probabilities (default rates). The forest averages these probabilities: p̂(x) = 1 T ∑T t=1 pt(x), where each pt(x) is a probability estimate from tree t. • Gradient Boosting: Each tree is a regression tree that predicts residuals in log-odds space. Trees do not output probabilities directly—they output corrections to the current log-odds: F (m)(x) = F (m−1)(x) + η ·hm(x), where hm(x) is the residual correction. Shapley values originated in cooperative game theory [30], where Lloyd Shapley addressed a fundamental question: how should players in a cooperative game fairly divide the total payout based on their contributions? The Shapley value is the weighted average of a player’s marginal contribution to all possible coalitions—the value the coalition gains by including that player. This game-theoretic concept found new life in machine learning through Lund- berg and Lee (2017) [24], who adapted Shapley values to interpret predictions. They coined the term SHAP (SHapley Additive exPlanations) to distinguish the machine learning application from the original game-theoretic method. In predictive modeling, features play the role of players in the cooperative game, and the prediction represents the total payout to be fairly distributed among them. This framework extends Turing’s additive evidence structure from simple linear models to arbitrarily complex machine learning systems. TreeSHAP [23] resolves this interpretability challenge. While the general SHAP computation requires evaluating 2p coalitions (exponential complexity), TreeSHAP achieves a remarkable breakthrough for tree-based models by exploiting their fixed structure to compute exact SHAP values e�ciently. Why TreeSHAP Matters for Credit Risk Unlike approximate methods like KernelSHAP that rely on sampling, Tree- SHAP computes exact Shapley values by exploiting the tree’s fixed decision paths. This exactness is critical for regulatory compliance: when a loan decision is challenged, TreeSHAP guarantees identical feature attributions every time—essential for adverse action notices and model documentation. Tree ensembles (Random Forests, XGBoost, LightGBM) have become the workhorses of modern credit scoring, outperforming logistic regression on nonlinear patterns. TreeSHAP provides principled, exact explanations for these powerful models without sacrificing their predictive accuracy. The Tree Structure Advantage TreeSHAP exploits a key property of tree models: their predetermined structure. Each prediction follows a fixed path defined by feature splits, and TreeSHAP traces this path to compute exact marginal contributions. Instead of evaluating all 2p possible feature coalitions, TreeSHAP only considers features that appear on the decision path. For ensembles, TreeSHAP computes SHAP values for each tree independently, then aggregates: Random Forests average across trees, while Gradient Boosting sums contributions scaled by the learning rate. This makes the algorithm both exact and e�cient. How TreeSHAP Works TreeSHAP exploits the tree’s fixed structure to avoid reasoning about all 2p feature coalitions.
