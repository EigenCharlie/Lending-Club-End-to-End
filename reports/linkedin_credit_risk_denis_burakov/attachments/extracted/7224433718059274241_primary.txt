Fisher scoring with Python
The Fisher Scoring algorithm is an iterative optimization                 Logistic Regression
algorithm that updates model parameters using the
expected or observed Fisher information matrix.

The `fisher-scoring` package contains Python Scikit-Learn
compatible implementations of the Fisher Scoring
algorithm for the standard logistic regression model and its
generalizations for multi-class and extreme imbalance:


■ FisherScoringLogisticRegression: Standard logistic
  regression using Fisher scoring with statsmodels-like
  outputs.
■ FisherScoringMultinomialRegression: Multinomial
                                                               Install with pip:
  logistic regression with Fisher Scoring for multi-class.
■ FisherScoringFocalRegression: Logistic regression with
                                                                 pip install fisher-scoring
  focal loss for imbalanced data with Fisher Scoring.
